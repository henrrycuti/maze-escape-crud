# Maze Escape - Laboratorio 07, Ejercicio 2 (CRUD con Room)

Vista "Monstruos" del proyecto final (diseñada en el laboratorio 6) con un CRUD simple:
- Create: formulario Nombre / Descripción / Velocidad (1 a 10) y botón Guardar
- Read: lista de monstruos que se actualiza sola (Flow de Room)
- Update: lápiz en cada tarjeta carga los datos en el formulario y el botón pasa a Actualizar
- Delete: papelera en cada tarjeta

Curso: Programación en Móviles - TECSUP
